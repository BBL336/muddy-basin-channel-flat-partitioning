# Supplementary code and Delft3D model setup

Supplementary materials for:

> **Size- and Geometry-Dependent Channel–Flat Partitioning in Macrotidal Muddy Basins**

## Contents

- [`centerline_extraction/`](centerline_extraction/): Python code for extracting basin centerlines and calculating the basin shape index. See the [centerline-extraction README](centerline_extraction/README.md).
- [`D3D_model/`](D3D_model/): Delft3D-FLOW and SWAN model input files for the long-basin and wide-basin experiments. See the [Delft3D model README](D3D_model/README.md).

The included files are provided to support reproducibility of the analyses and numerical experiments described in the manuscript.
