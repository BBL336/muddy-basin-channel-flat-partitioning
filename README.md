# muddy-basin-channel-flat-partitioning

This repository contains the supplementary code and Delft3D numerical model setup associated with the manuscript:

"Size- and Geometry-Dependent Channel–Flat Partitioning in Macrotidal Muddy Basins"

The repository includes:

(1) Python scripts for channel centerline extraction from tidal basin morphology.

(2) Delft3D model configuration files, including model grids, boundary conditions, and input parameters used for numerical simulations.

The materials are provided to facilitate reproducibility and further research on channel–flat partitioning in macrotidal muddy basins.
